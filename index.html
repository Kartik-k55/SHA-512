#️⃣

Cryptographic Hashing

A deterministic mathematical algorithm that maps arbitrary-length input data to a fixed-size 512-bit digest. The same input always produces the exact same 128-hex-character output.

🛡️

One-Way Property (Pre-image Resistance)

Computationally infeasible to reverse. Given a 512-bit hash digest h, finding any original input message m such that SHA512(m) = h would require on average 2512 operations.

⚡

Collision Resistance

It is practically impossible to find any two different messages m1 ≠ m2 such that SHA512(m1) = SHA512(m2). Security strength against collisions is 2256 operations.

🌊

Avalanche Effect

Strict diffusion design guarantees that flipping a single bit in the input message causes an average of 50% of the 512 output bits to flip, preventing correlation and differential attacks.

🧩

Message Padding

Messages are aligned to 1024-bit block boundaries by appending a '1' bit (0x80 byte), required zero padding bytes, and a 128-bit big-endian representation of the original message bit length.

🔄

Compression Function

Utilizes the Davies-Meyer construction with 80 distinct compression rounds, mixing 64-bit non-linear functions (Ch, Maj, Σ, σ) and prime-derived round constants K0..79 modulo 264.

⚙️

How SHA-512 Works

Step-by-step pipeline of the 512-bit message digest generation process

1

Message Input

The user provides arbitrary text or binary data of length L bits.

Input: "Hello World" (Length: 11 characters = 88 bits)
2

UTF-8 Encoding

Convert the text string into a sequence of raw byte values (0x00 - 0xFF).

Bytes: [0x48, 0x65, 0x6c, 0x6c, 0x6f, 0x20, 0x57, 0x6f, 0x72, 0x6c, 0x64]
3

Padding

Append a single '1' bit (byte 0x80), followed by k zero bytes so that total length modulo 128 bytes equals 112 bytes (896 bits mod 1024).

Append 0x80, then 100 zero bytes (0x00 ... 0x00)
4

1024-bit Block Formation & Length Append

Append the original message length L as a 128-bit big-endian unsigned integer (16 bytes). The data is now partitioned into 1024-bit (128-byte / sixteen 64-bit words) blocks.

Length = 88 bits → 0x00000000000000000000000000000058 (16 bytes appended)
5

Message Schedule W[0..79]

For each 1024-bit block, copy the 16 words into W[0..15], then expand words W[16..79] using the small sigma functions: W[t] = σ1(W[t-2]) + W[t-7] + σ0(W[t-15]) + W[t-16] mod 2^64

6

Initialize State Variables H0 - H7

Initialize eight 64-bit working registers (a, b, c, d, e, f, g, h) from fractional parts of square roots of first 8 primes.

H0 = 0x6a09e667f3bcc908, H1 = 0xbb67ae8584caa73b, ..., H7 = 0x5be0cd19137e2179
7

80 Compression Rounds

Iteratively transform registers through 80 rounds using round constants K0..79, message words W0..79, and logical functions Ch, Maj, Σ0, Σ1.

T1 = h + Σ1(e) + Ch(e,f,g) + K[t] + W[t]; T2 = Σ0(a) + Maj(a,b,c); a = T1 + T2; e = d + T1;
8

Final 512-bit Digest

Add round output registers to H0..H7 (modulo 264) and concatenate into a single 512-bit string of 128 hexadecimal digits.

Output: 128 Hexadecimal Characters (e.g. 2c74fd17edafd80e8447b0d46741ee24...)
📐

Algorithm Details & Mathematical Functions

The six 64-bit bitwise functions and compression round equations

Ch(x, y, z) Choose Function
Ch(x, y, z) = (x ∧ y) ⊕ (¬x ∧ z)

Acts as a bitwise multiplexer: for each bit position, if bit in x is 1, choose bit in y; otherwise choose bit in z.

Maj(x, y, z) Majority Function
Maj(x, y, z) = (x ∧ y) ⊕ (x ∧ z) ⊕ (y ∧ z)

Returns 1 for a bit position if the majority (two or three) of the corresponding bits in x, y, z are 1.

Σ0(x) & Σ1(x) Big Sigma Functions
Σ0(x) = ROTR28(x) ⊕ ROTR34(x) ⊕ ROTR39(x)
Σ1(x) = ROTR14(x) ⊕ ROTR18(x) ⊕ ROTR41(x)

Performs multiple 64-bit circular right rotations and XOR combinations to provide intra-word diffusion in compression rounds.

σ0(x) & σ1(x) Small Sigma Functions
σ0(x) = ROTR1(x) ⊕ ROTR8(x) ⊕ SHR7(x)
σ1(x) = ROTR19(x) ⊕ ROTR61(x) ⊕ SHR6(x)

Used during message expansion to compute schedule words W[16..79]. Combines rotations with logical right shifts.

Round Compression Formulas (Modulo 264)
T1 = (h + Σ1(e) + Ch(e, f, g) + Kt + Wt) mod 264
T2 = (Σ0(a) + Maj(a, b, c)) mod 264
h = g;   g = f;   f = e;   e = (d + T1) mod 264;   d = c;   c = b;   b = a;   a = (T1 + T2) mod 264

Each round injects one 64-bit round constant Kt and one message word Wt into the working state, rotating all variables and mixing non-linear functions into registers a and e.
